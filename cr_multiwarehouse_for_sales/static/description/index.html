Sale Multi Warehouse

Live Preview

Features

  • Multi Warehouse for Sales Order.
  • Delivery Order Based on Warehouse.
  • Change Warehouse on Sale Order.
  • Set warehouse for Products.
  • Easy to use.

Enable Multi Warehouse Configuration

  • Enable "Allow Warehouse in Sale Order Line" features from within Sale configuration.

Warehouse on Products

  • The user can choose "Sale Warehouse" on the product; the chosen warehouse will be shown on product variants.


Multi Warehouse on Sale Order

  • When a product is chosen, the relevant warehouse will be immediately added to the sale order line. The user can also alter the warehouse on the sale order line..

Delivery Order Based on Warehouse

  • After confirming the sale order, the user can see the delivery order that was made depending on the warehouse that was chosen.

  • In a tree view, the user can view all created transfers depending on warehouse.

  • The user can view newly created delivery orders for various warehouses in the form view.
