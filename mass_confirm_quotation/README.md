Overview :
----------
The Mass Confirm Sale Quotation Odoo app simplifies sales order management by allowing users to perform bulk actions on multiple quotations. With this app, users can quickly confirm quotations in a single operation, saving time and reducing manual effort. The app provides a user-friendly interface to select multiple quotations and apply the desired action based on the user's choice, improving efficiency and workflow in sales order processing.

Features :
----------
 • Bulk Confirmation: Confirm multiple quotations simultaneously with a single action.

 • User-Friendly Wizard: A simple wizard interface allows users to select and apply operations easily.

 • State Validation: Ensures only applicable quotations are processed.

Installation Process :
----------------------
Follow these steps to install and use the Document Customization module for Sale Orders in Odoo.
Steps :
    a. Download the Module
        1. Download the Mass Confirm Sale Quotation module from the Odoo App Store.
        2. Save the downloaded module file (usually a .zip file) to your odoo addons.
        3. Log in to your Odoo system as an Administrator.
        4. Navigate to the Apps module on your Odoo dashboard.
    b. Install the Module
        1. Once the module is uploaded, you will see it appear in the Apps list.
        2. Click the Install button next to the Mass Confirm Sale Quotation module.
        3. Odoo will install the module for you. Once it's done, the module is ready to use!
    c. Troubleshooting
        1. If you don’t see the module in the Apps list : Ensure that you have activated the developer mode by going to settings -> Activate Developer Mode.
