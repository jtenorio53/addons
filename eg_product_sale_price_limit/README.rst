Product Sale Price Limit
=========================

This module allows users to set the minimum and maximum sale prices for products. It also provides an option to grant specific users access to set unit prices that differ from the predefined price limits.

Features
--------

- Set minimum and maximum sale prices for products or product variants.
- Users can see the minimum and maximum price limits when creating a quotation.
- Displays a validation error if the user tries to enter a price outside the defined limits.
- Users with the "Confirm product sale price" access right can override the price limits without receiving a warning.

How to Use
----------

1) Product Variants View:  
   Navigate to Sales → Products → Product Variants. Here you can see and add the Minimum and Maximum prices for each product variant.

2) Quotation View with Different Price:  
   When creating a quotation, if the unit price entered does not match the min-max limits, users can see the min and max price limits displayed.

3) Validation Error View:  
   If a user enters a unit price above the maximum price limit and confirms the quotation, a validation error will be raised.

4) Users View:  
   Users with the "Confirm product sale price" access right can set the price freely without receiving a warning about the price limits.

5) Quotation Confirm with Different Price:  
   If a user has the "Confirm Product Sale Price" access right, they will not receive a warning when confirming a quotation with a price outside the defined limits.
